# CRYON CLIENT 0.10.7

## Graphite / Frost theme refresh

- Replaced the mixed cyan, bright-blue and orange visual accents with a consistent graphite and soft silver-blue palette.
- Refined sidebar navigation, home launch control, profile cards, catalogue controls, forms, panels and notifications.
- Added subtle borders, restrained shadows, consistent rounded corners and clearer keyboard focus states.
- Preserved existing renderer IDs, navigation, profile handling, account flows, mod management and server controls.

This release is a presentation-only refresh. It does not intentionally change launcher behavior.
