# CRYON CLIENT 0.10.8

## Category navigation refresh

- Increased the desktop navigation rail width for clearer category selection.
- Reworked category buttons into larger icon-first vertical controls.
- Removed individual icon tiles and the blue active stripe in favour of a single understated selected-category surface.
- Kept the Graphite / Frost palette and retained all existing page IDs, navigation data attributes, and click behaviour.
- Added a smaller responsive layout for narrow windows.

This release changes presentation only; it does not add or remove launcher functionality.
