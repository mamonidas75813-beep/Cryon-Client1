# CRYON CLIENT v0.11.0 — Partner Servers

- Added a featured Partner Servers area to the home sidebar.
- Added Solvane MC (`play.solvanemc.fun`) with the supplied server logo.
- Added a Your Servers category for user-managed community servers.
- Added validated add/remove actions and live Java server status cards.
- Each profile receives the featured Solvane MC entry at the top of its `servers.dat` on first launch, including the 64×64 supplied server icon and a gold star in its multiplayer name. Selecting any server with PLAY moves that destination to the top before connecting.
- PLAY uses Minecraft Quick Play for 1.20+ and legacy server/port launch arguments for older versions.
- Server entries are isolated per Minecraft profile; existing multiplayer entries are preserved.
