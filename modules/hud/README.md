# CRYON game-side HUD module

The launcher-side HUD Editor was removed from the current CRYON UI. This folder documents the optional Fabric client HUD implementation at `../mods/nova-hud-fabric`, which targets Minecraft 1.21.1 only. The module reads `config/nova-hud.json`; its settings must be edited through its own JSON file or future in-game configuration UI. Other supported Minecraft versions require separately compiled, version-matched mod builds.
