# 0.11.5 — Rebuilt Partner Manager

- Add, edit and remove configured partners from the launcher without editing JSON.
- Persistent writable partner config outside app.asar, with a first-launch bundled seed.
- Open config folder and reload manually edited JSON without restart.
- Invalid config shows an actionable error without overwriting the file.
- Optional local logo selection and generated 64×64 Minecraft icon.
- Overview displays all configured partners in a scrollable rail; directory and Overview share the same list.
- Retains Java server status, ranking and Quick Play.
- Local configuration only; no remote sync or developer-only authentication.
