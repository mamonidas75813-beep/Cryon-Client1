# CRYON CLIENT 0.10.9

## Account-first skin management
- Removed Performance and Cosmetics from the primary category rail.
- Added a Skins action to each saved account card.
- Opening Skins first selects the corresponding saved account, then opens the existing Minecraft skin manager for that identity.
- Offline/local accounts can still preview PNG skins; uploading to Minecraft remains limited to eligible Microsoft Minecraft accounts.
- Added account-link status and moved default-account / remove actions into the account card menu.
- Kept the underlying Performance page and preset logic intact; only its primary navigation category was removed.
